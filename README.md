# HB Materiais — Protótipo Digital (v1)

Demonstração comercial navegável de um novo site para a HB Materiais, produzida pela Propagou para apresentação de oportunidades de evolução digital.

## Demonstração

**Endereço previsto após ativar o GitHub Pages:** https://jaysonrw.github.io/siterhbv1/

## O que inclui

- Página inicial responsiva com a marca oficial da HB;
- Categorias, pesquisa e produtos ilustrativos;
- Carrinho de compras de demonstração;
- Montagem de lista para orçamento, sem envio real;
- Apresentação do conceito B2B para profissionais e empresas;
- Navegação desktop e mobile.

## Aviso importante

Este é um **protótipo conceitual**. Produtos, valores e condições são fictícios. Não existem pagamento, integração com estoque, emissão de nota fiscal ou envio real de pedidos/orçamentos.

## Publicação

Este repositório possui o arquivo `.github/workflows/deploy-pages.yml` para publicação automática ao enviar alterações para a branch `main`.

Se o site ainda não estiver acessível, no GitHub, acesse **Settings → Pages → Build and deployment → Source: GitHub Actions**. Depois acompanhe a aba **Actions** para confirmar que o deploy foi concluído.

## Estrutura

O arquivo `index.html` contém a apresentação estática e seus estilos e scripts. Pode ser hospedado diretamente pelo GitHub Pages; não requer instalação de dependências.
